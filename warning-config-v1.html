适用范围

大区规则用于该业务大区下的基础口径，特殊规则默认必须先选大区。
大区取自落货纸业务归属，不是国家或港口的地理上级。
国家级规则用于某个国家整体口径特殊的场景。
选择港口后自动带出所属国家，国家字段置灰且不可修改。
船公司支持多选；保存时会按所选船公司拆成多条独立规则。“通用”不能与指定船公司同时选择。

批量修改免费期

批量修改仅调整所选规则的海运免费期和海铁免费期；不影响适用范围和起算节点。

未提箱配置帮助
先判断你要维护的是大区、国家还是港口，再按优先级理解谁会生效。

先判断你要配哪一层

1.如果你要维护整个大区的口径，就配置大区层级。例如北美区负责人，维护“北美区 + 通用”或“北美区 + 指定船司”。
2.如果你要维护某个国家的口径，就配置国家层级。例如美国负责人，维护“北美区 + 美国 + 通用”或“北美区 + 美国 + 指定船司”。
3.如果你要维护某个港口的口径，就配置港口层级。例如 Long Beach 负责人，维护“北美区 + 美国 + Long Beach + 通用”或“北美区 + 美国 + Long Beach + 指定船司”。
4.如果只是某个船司特殊，不要新开一层，只在你当前负责的层级下补一条该船司特例即可，其他船司继续走通用规则。

取值逻辑

大区取自落货纸销售/业务归属，特殊规则默认必填。
国家来自国家主数据，用于国家级整体口径差异。
港口来自 `b_port`，选择港口后自动带出国家，国家置灰不可改。
船公司“通用”表示当前层级下未单独拆船司时默认走这条。

优先级说明

港口 + 船司 港口 + 通用 国家 + 船司 国家 + 通用 大区 + 船司 大区 + 通用 默认兜底
大区负责人你配置的是大区规则，只有在没有更细的国家规则、港口规则时才生效。
国家负责人你配置的国家规则会覆盖同大区下的大区规则；但如果某个港口又单独配置了港口规则，则港口规则优先。
港口负责人你配置的港口规则优先级最高；如果同一个港口下某个船司又单独配置了船司特例，则该船司特例优先于港口通用。
统一原则先比层级：港口 > 国家 > 大区；同层级再比船司：指定船司 > 通用。
